# Basis and limits

The 2026-09-20 36-run instruction/skill-exposure pilot found identical focused
code-oracle success across native, compact and full on small ADK regressions.
Additional instructions did not consistently improve elapsed time or usage.
This supports testing less default process, not claiming that a particular
routing threshold is scientifically calibrated.

Existing components reused: pkg/spec/gates path classification, workflow CLI
command registration, current platform routers and shared root guidelines.
Existing adaptive-quality controls model role profiles and is deliberately
not changed. The new classifier uses declared structured facts rather than
prompt length, keyword scoring or an extra model call.

Initial policy thresholds (<=2 paths/80 estimated changed lines for inline;
>=6 paths/>300 lines for planned) are conservative starting heuristics, not
benchmarked optima. Counts never establish risk or independence. Caller facts
must be reassessed when scope changes or attempts fail.
