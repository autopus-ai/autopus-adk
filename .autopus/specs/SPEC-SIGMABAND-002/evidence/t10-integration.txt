Findings
--------
- JSON envelope: output_json.go maskHomePath turns $HOME into ~ in every string, so
  local_patches[].patch_path under a default user cache directory reads ~/Library/Caches/...;
  the text output and the BS keep the absolute path. CLI-wide contract, not a SIGMABAND-002
  change; a consumer needs the text output or ~ expansion.
- Observation (untested): run inside an agent session, band passes CLAUDECODE, CLAUDE_CODE_*
  (messaging socket and token), and ORCA_AGENT_HOOK_TOKEN to the confined claude, because
  bandProviderUnsetEnv lists none of them; the confined session has only Read, Grep, and Glob,
  so no tool can use them, but adding them to the unset list is cheap hardening.
