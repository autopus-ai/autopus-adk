# Harness instruction and skill exposure pilot — 2026-09-20

For small source-local regression repairs, this pilot did not establish a quality benefit from adding project harness instructions or a larger skill catalog. All three arms produced code that passed the independent focused acceptance tests. Native completed all 12 tasks within the deadline; compact and full each timed out once after producing a passing patch. Native had the lowest total elapsed time. Keep the existing compact default; this result does not justify making full the default or removing the harness from complex work.

## Results

| --- | ---: | ---: | ---: | ---: | ---: |
| Native CLI | 0 | 12/12 | 12/12 | 14.93 min | 66.01 s |
| Compact split (existing default) | 38 | 12/12 | 11/12 | 16.39 min | 78.98 s |
| Full catalog (explicit opt-in) | 71 | 12/12 | 11/12 | 17.41 min | 97.41 s |

Compact took 9.8% more total time than native; full took 16.6% more. Native was fastest on 7 tasks, compact on 3 and full on 2. These are descriptive observations from one run per task/arm, not significance claims. Setup, compilation warmup and independent grading are outside elapsed agent time; timeout time is included.

## What was controlled

- Source: `a05ce69df9dc03493b8c5de0ab9299459195e8d8`; 12 distinct single-mutation repairs. Original tests passed and seeded versions failed behaviorally before trials. A duplicated task was replaced before any corpus model execution.
- Runtime: Codex 0.155.1, requested `gpt-6-astra`, medium effort, 180s per run, serial execution, all six arm orders twice. Zero human intervention or outcome-driven retries.
- Native had no project harness; compact/full used generated root instructions and skill surfaces. Hooks, memory, browser/apps and multi-agent capabilities were disabled in all arms. This is an exposure ablation, not the complete Autopus workflow.
- Every trial had a fresh seeded Git history. An independently graded seeded copy received only allowed production edits, with original immutable tests. Missing or symlink production files could not fall back to the correct original.
- Actual Seatbelt checks allowed workspace/Go operations and denied source/protocol siblings, symlink escape and the original repository. This is local-command isolation, not a proof about every possible auto-loaded context surface.
- A no-model debug prompt inspection advertised 0/38/71 project skills and the same 17 external skills. That diagnostic uses normal user config; actual exec used ignore-user-config equally. The diagnostic is not an exact prompt capture of every model call.

## Limits and operating decision

The corpus is ADK code with small injected regressions and existing visible tests. It is not a random production sample, independent held-out benchmark, new-feature delivery test or multiagent evaluation. The same requested model alias does not attest a fixed provider-side model snapshot. Provider cache state, service latency and time-of-day are uncontrolled despite balanced order. One observation per task/arm cannot establish repeatability. The all-pass code oracle also creates a quality ceiling.

Maintain the current compact split default and keep full opt-in. For small fixes, this evidence favors testing a thinner path with targeted instruction/skill loading; it does not justify a broad automatic default change from this pilot alone. The next useful evaluation is repeated, harder held-out tasks with actual integration acceptance, plus a separately budgeted multiagent comparison. No production defaults were changed by this experiment.
