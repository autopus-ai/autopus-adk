## What changed on main since v0.51.9

- `auto ci report` lints the remote default branch's workflows when the
  checkout is only behind it, without rewriting `.git/index` (#347, #357).
- `auto verify stop` has a time budget (`hooks.verify_stop_budget`, 1m-30m,
  default 8m). A run that exhausts it is never recorded or reported as
  passed; a suspected hang blocks once per tree (#348, #353, #358, #359).
- Step cancellation reaches descendants outside the process group and, on
  Windows, the whole Job Object (new `pkg/procgroup`, #355).
- `cpu_gate` (default off; `AUTOPUS_CPU_GATE=on|off`) refuses CPU-heavy Bash
  commands outside an `auto disk lease --cpu N` while leased work is
  protected (#349). Disk/CPU gate config is read from the nearest
  `autopus.yaml`; auto reclaim still runs from the session cwd so the
  session's worktree stays protected; heredoc scripts, line continuations
  and redirections are classified as the shell runs them (#356).
- `auto doctor` text verdict follows the lines it printed: FAIL only under an
  ERROR line, WARN naming its sections otherwise; repeated generation
  diagnostics print once (#350).
- Escape lessons and checklist ids carry a suffix so two branches never
  collide; `pipeline.jsonl` merges with `merge=union` and readers dedupe by
  id + timestamp (#352, #354).
- Pilot C benchmark runner for Claude Code (scripts only, #351).

New config keys (`hooks.verify_stop_budget`, `hooks.cpu_gate`) are rejected by
older `auto` binaries; that is why both stay optional and `cpu_gate` is
recommended through its environment variable.
